Full-stack developer from Viet Nam 🇻🇳 with a strong focus on backend engineering. I am open to full-stack and backend roles on product teams and welcome collaboration on healthcare, enterprise, and fintech products.

## Engineering principles

- Keep the architecture clean and easy to read.
- Build simple systems first, then scale them when real usage needs it.
- Design APIs and databases around how people actually use the product.
- Treat performance and developer experience as part of the work.
- Review and document code so the next person can change it safely.
